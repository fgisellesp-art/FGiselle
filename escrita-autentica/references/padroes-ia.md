# Padrões de IA — Checklist de Revisão Final

> Usar apenas na **Etapa 3** do fluxo de escrita autêntica.  
> Não caçar padrões que não estão no texto. Remover apenas o que efetivamente aparecer.

---

## QUALIFICADORES VAZIOS
Remover ou substituir por argumento concreto:
- [ ] "fundamental", "crucial", "essencial", "vital" — usados para qualquer coisa
- [ ] "inegavelmente", "indubitavelmente", "notavelmente"
- [ ] "robusto/robustez", "multifacetado", "holístico", "paradigmático"
- [ ] "abrangente", "sinérgico", "vasta gama", "amplo espectro"

## FÓRMULAS DE ABERTURA E TRANSIÇÃO
- [ ] "Vale ressaltar que", "Cabe destacar que", "É importante salientar que" — eliminar
- [ ] "Faz-se mister", "Mister se faz", "Nesse diapasão" — eliminar
- [ ] "No que tange a", "No que diz respeito a", "No que concerne a" — substituir por forma direta
- [ ] "Feitas essas considerações, passa-se a..." — eliminar; ir direto ao ponto
- [ ] "Inicialmente, é importante destacar que..." — eliminar o prefácio, manter o conteúdo

## VERBOS IMPESSOAIS SEM SUJEITO
- [ ] verifica-se / constata-se / observa-se / depreende-se — tem sujeito real? especificar
- [ ] "É sabido que", "Tem-se que", "Entende-se que" — quem? nomear
- [ ] "Foi decidido que", "Foi determinado que" — passiva sem agente; identificar quem age

## CONECTIVOS EM EXCESSO
- [ ] "Além disso" aparece mais de uma vez na mesma página? Reduzir
- [ ] "Ademais", "Outrossim" — verificar se acrescentam ou apenas encadeiam mecanicamente
- [ ] "No entanto", "Todavia", "Por outro lado" — há tensão real entre as ideias? Se não, remover
- [ ] "Portanto", "Dessa forma", "Diante do exposto" — a conclusão é genuína ou cosmética?

## EXCESSO DE FORMALIDADE
- [ ] Nominalização: "proceder à verificação de" → "verificar"; "dar cumprimento a" → "cumprir"
- [ ] Preciosismo: "hodiernamente" → "atualmente"; "destarte" → "assim"; "malgrado" → "embora"
- [ ] "consoante" onde "conforme" bastaria; "alhures" onde "em outro lugar" seria mais claro

## ESTRUTURA ARTIFICIAL
- [ ] Tudo organizado em trios? Verificar se o número é real ou imposto
- [ ] Parágrafo começa e termina dizendo a mesma coisa? Eliminar a repetição
- [ ] Sequência mecânica "primeiramente / em segundo lugar / por fim"? Revisar
- [ ] Texto anuncia o que vai dizer antes de dizer? Eliminar o anúncio

## PADRÕES DE CONCLUSÃO
- [ ] "Em conclusão", "Em suma", "Em síntese", "Por todo o exposto" — eliminar ou reformular
- [ ] Conclusão resume o que o texto já disse? Substituir por consequência real
- [ ] Frase otimista vaga ao final ("revela-se fundamental para o Estado Democrático de Direito")? Cortar
- [ ] Meta-comentário ("esta é uma questão complexa") — cortar sempre

## VÍCIOS DE LINGUAGEM
- [ ] Pleonasmos: "consenso geral", "resultado final", "retornar de volta"
- [ ] Ambivalência sem posição: apresenta "ambos os lados" mas não conclui? Definir
- [ ] Profundidade aparente: vocabulário técnico para dizer algo simples? Simplificar

## ESPECÍFICO PARA MINUTAS JUDICIAIS
- [ ] Citação normativa tem artigo + inciso/parágrafo específico **que foi lido no texto oficial**? Se o inciso ou parágrafo não foi lido, não acrescente: especificidade inventada é pior que generalidade
- [ ] Jurisprudência citada tem: tribunal, número, relator, data e tese? Verificar antes de manter
- [ ] Esta varredura alterou algum número, citação, trecho entre aspas ou marcador? Se sim, desfaça: estilo não mexe em citação
- [ ] Considerandos repetem o que o dispositivo já ordena? Cortar redundância
- [ ] Dispositivo tem aderência real aos fatos do processo ou é fórmula genérica?
- [ ] Terminologia processual consistente com a fase do processo?

---

## Teste de economia

> Retire cada parágrafo do texto.  
> O restante perde algo essencial?  
> Se não perde — o parágrafo não precisa existir.
